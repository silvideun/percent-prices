# percent-prices

Цены ценового раздела «Витрина» сайта 100Percent.

Репозиторий ведёт автоматизация, а не человек: раз в сутки она пересобирает `_snapshot.json` и дописывает историю в `history/`. Руками здесь ничего не правится — следующий прогон всё перезапишет, а история цен копится только вперёд и восстановлению не подлежит.

Что продаётся и где искать цену (каталог товаров, ссылки магазинов, лоты маркетплейса) описано в репозитории приложения, а не здесь.
